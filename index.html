Учебные проекты

Backend

  • MY LIBRARY (FastAPI)

    RESTful API для управления каталогом книг и авторов. БД спроектирована через SQLAlchemy ORM, данные валидируются через Pydantic. Бизнес-логика изолирована в слой Repository, маршрутизация настроена через APIRouter.

  • ToDo-List (Django)

    Веб-приложение для управления задачами на базе архитектуры MVT. Спроектирована БД с отношениями через Django ORM, реализована полная CRUD-логика, серверная валидация и защита от CSRF. Настроена панель администратора.

  • Симулятор аукциона (консольное приложение)

    Реализована симуляция торгов в реальном времени. Применены паттерны Observer (для уведомления участников о ставках) и Strategy (для создания ботов с разным поведением). Внедрена валидация ставок и защита баланса.

Frontend

  • Background Color Changer

    Интерактивная страница для смены фонового цвета по нажатию кнопки. Реализована обработка событий JavaScript и динамическое изменение CSS-стилей. Проект для отработки работы с DOM и событиями.

  • Таймер обратного отсчёта

    Приложение для отсчёта времени до заданного события. Реализована логика подсчёта дней, часов, минут и секунд с автоматическим обновлением интерфейса. Отработана работа с объектом Date и setInterval.

  • To-Do List

    Классический менеджер задач с возможностью добавления, отметки о выполнении и удаления дел. Реализован базовый CRUD на фронтенде.
