# Интерактивное Резюме

## Одностраничный сайт-резюме, созданный с помощью базовых технологий HTML, CSS и JavaScript.

[Ссылка на сайт](https://petrushka00.github.io/buisness-card/)

## Основной функционал

*   **Адаптивный дизайн:** Страница корректно отображается на компьтере, телефоне и планшете.
*   **Интерактивные навыки:**
    *   **Категории:** Навыки разделены на группы (Frontend, Backend, Tools, Database). При клике на кнопку категории отображаются только соответствующие навыки.
    *   **Поиск:** Текстовое поле для поиска навыков по названию (регистронезависимый поиск в реальном времени).
    *   **Совместная работа:** Поиск и фильтр по категориям работают одновременно.
    *   **Обратная связь:** При отсутствии результатов поиска или фильтрации выводится сообщение "Ничего не найдено".
*   **Светлая/Тёмная тема:** Переключение между темами происходит без перезагрузки страницы. Выбранная тема сохраняется в `localStorage` и восстанавливается при следующем визите. По умолчанию стоит тёмная тема
*   **Панель навигации:** Позволяет переходить по разделам. Реалзована с помощью тега <a> и ссылки на id секции. 
*   **Карточки:** На сайте имеются карточки с проектами, по которым можно перейти на соответсвующий репозиторий на GitHub, и карточки с сертификатами, по которым можно перейти на соответсвующий файл на Google Drive.
